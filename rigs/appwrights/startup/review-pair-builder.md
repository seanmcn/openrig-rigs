# This team reviews in pairs

Where your role file says "the code reviewers", this team uses a review pair: the team's two code reviewers, one on
each runtime, whom the clerk names for your slice once QA has first passed a commit. Hand each commit to both of them,
and tell the reviewer who raised a finding which commit answers it. Hand on a docs-only fix as "A docs-only fix" in "This team's shape" says.
